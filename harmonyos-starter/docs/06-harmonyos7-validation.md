## 发现的问题与修复范围

1. **设置保存后清空**：原设置页的共用 Builder 字段没有可靠地更新页面持有的状态。改为每个 TextInput 直接绑定页面状态，并在设置保存前取值；旧空值回退到教师默认。已通过真机编辑和保存核对。
2. **回复卡片仍显示 running**：终态更新时使用新的消息对象，ForEach 固定 ID 导致旧项视图复用。按用户明确授权，将消息项标识包含状态，终态和正文随之刷新。已验证 success、failed 和 cancelled。
3. **默认模型只返回思考内容**：用与 App 完全相同的请求在电脑复现，finish_reason 为 length，正文为空。针对用户指定的默认 Qwen 模型增加 `enable_thinking: false`；其他模型不附带该参数。修复后手机实际收到正文。
4. **默认服务配置**：按用户要求加入 TeacherDefaults；没有把个人签名或用户凭据写入测试输出。该课堂密钥位于源码中，公开分发前必须替换或移除。

以上属于原有界面或模型服务配置问题，不能归因于 HarmonyOS 7。
