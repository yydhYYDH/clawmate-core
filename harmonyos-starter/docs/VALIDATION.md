- 未把电脑测试替身、课堂检查服务或模型返回的 success 当作真实设备任务成功。

## 复现检查

在独立目录中：

```bash
bash scripts/check.sh
bash scripts/build.sh
```

测试不需要连接手机。构建会使用本地工具的缓存目录。生成的未签名文件在 `entry/build/default/outputs/default/entry-default-unsigned.hap`。

下一阶段按 [首次运行指南](01-first-run.md) 配置签名和服务，再填写 [A01–A15 真机验收表](04-acceptance.md)。只有教师在 HarmonyOS 源设备完成必做项，才适合将其称为“已经验收的教学起点”。
