# 基础 GUI 助手改造与验收

## 已实现

- 成功、失败、暂停、取消独立处理。只有 `done` 且显式成功状态才显示完成。
- 初始化也受到 `finally` 保护；退出时停止云端请求、释放 HDC 和后台任务，并尝试返回聊天页。
- 取消云端等待会主动结束 Promise，即使底层 `destroy()` 不回调也能收尾。单次模型请求上限 90 秒，任务上限 10 分钟。
- Planner 与系统应用名称解析共用 OpenHarmony 应用目录；保留显式包名优先规则。
- 每个任务独立保存正文、技术日志和运行状态。日志默认折叠、浅色显示，折叠时仍持续更新；正文同时追加。
- 每次成功执行动作后输出中文操作回执。下一轮截图决策可通过 `progress` 返回可见成果；最终可通过 `summary` 返回结果。
- 操作回执与截图确认分开：点击成功不会直接宣称业务完成。不返回 `progress`/`summary` 的模型仍有本地回执和最终状态。
- 最新正文后显示当前阶段计时；超过 30 秒无事件会显示等待提示。终止后固定总耗时。界面最多保留最近 400 条日志，hilog 仍接收完整过程。
- 输入框保持普通文本类型；提供系统输入法选择框、当前输入法名称和系统设置入口。开发板未提供独立输入法配置入口时回退系统设置。

## 中文输入的设备依赖

这台设备的输入法列表只有 Kika，实机键盘为英文，未发现中文/拼音候选模式。

目前验证的是中文字符串能被聊天框接收，以及 Agent 使用的命令能写入中文。
**输入法选择功能不会给英文键盘增加拼音词库。用户手动拼音输入仍需先安装适配 OpenHarmony/API 18 的中文输入法，然后通过“切换输入法”选择它。此项尚未在设备上完成中文拼音键入验收。**

不能把 HarmonyOS 零售设备的输入法包或 Android APK 当成这台 OpenHarmony 开发板可直接安装的输入法。

## 重复验证

1. 在 DevEco 配置与已有应用匹配的签名后，构建并安装。
2. 点击“切换输入法”，选择已安装输入法；用系统设置管理输入法。
3. 输入“打开计算器”，确认正文独立更新；运行期间展开、折叠日志。
4. 输入需要多个动作的任务，确认每个已执行动作都有回执，等待期间计时更新；停止后不再执行新动作。
5. 检查失败/暂停状态，不应出现“已完成”。

普通聊天问答、画像、收藏、推荐、定时工作流不在此次改造范围内。
